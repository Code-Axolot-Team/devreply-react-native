# Contributing

Thanks for helping. **Issues are the best way in**: bugs, questions and ideas all welcome.

- **Bug:** open an issue with the template. The package version, iOS or Android version, and steps to reproduce help most.
- **Idea:** open an issue and tell us the problem it solves for your users.
- **Pull requests** are welcome for fixes. This repository is published from DevReply's main repository, so
  we apply an accepted change there and publish it here with you credited in the commit.

Keep the SDK dependency-free, native to its platform, and never breaking for apps already shipped with it.
